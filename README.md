# MERN Starter

A production-ready MERN Starter Kit built with:

- React
- Vite
- Tailwind CSS
- Express
- MongoDB
- JWT (Coming Soon)

## Features

- Clean Folder Structure
- React Router
- Axios Setup
- Express Boilerplate
- MongoDB Connection
- Global Error Handling
- CORS Configuration

## Installation

### Clone

```bash
git clone <repo>
```

### Install

```bash
npm install
cd client && npm install
cd ../server && npm install
```

### Run

```bash
npm run dev
```
